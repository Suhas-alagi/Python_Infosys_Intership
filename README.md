# Air Quality Prediction System

## Features
- Cleans and preprocesses air quality data
- Trains a model to predict pollutant averages
- Simple web dashboard for predictions

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Preprocess data: `python scripts/preprocess.py`
3. Train model: `python scripts/train_model.py`
4. Run web app: `python app.py`
